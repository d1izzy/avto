# Кабинет GRAPHITE

Вход: https://avto-d1izzys-projects.vercel.app/s/graphite/owner

Введите почту и пароль существующей учётной записи владельца. Вход также доступен по значку человека справа вверху главной страницы.

- **Обзор** — ближайшие записи в порядке времени, текущая работа.
- **Записи** — поиск по клиенту или услуге, фильтр статуса, начало работы, завершение, отмена.
- **Календарь** — записи на выбранную дату по времени студии.
- **Услуги** — название, описание, цена, длительность, активность и доступные боксы. Новая услуга требует привязки к боксу.
- **Боксы** — добавление и редактирование рабочих мест. Новый бокс нужно выбрать в настройках соответствующей услуги.
- **Клиенты** — контакты из истории записей.
- **Настройки** — данные студии, обложка, галерея по HTTPS-ссылкам, правила записи и отмены.

## Назначить администратора

Это выполняется владельцем проекта Supabase, а не через публичную регистрацию сайта:

1. В проекте serviceslot откройте Authentication → Users и создайте сотруднику отдельную учётную запись. Скопируйте User ID.
2. В Table Editor → tenant_memberships добавьте строку: tenant_id — ID нужной студии, user_id — скопированный ID, role — manager. Для GRAPHITE tenant_id: 10000000-0000-0000-0000-000000000001.
3. Сотрудник входит на страницу кабинета со своей почтой и паролем. Manager может редактировать услуги и настройки. Не передавайте сотрудникам service-role ключ.

Для удаления доступа уберите соответствующую строку tenant_memberships. Проверки доступа выполняются базой данных при обращении к ней.

## Что видит клиент

Запись проходит через услугу → дату и время → автомобиль и контакты → подтверждение.
Ссылка подтверждения даёт доступ к этой записи; её не следует публиковать.
«Моя запись» хранит только ссылки на записи на текущем устройстве.
Email, SMS и push не подключены. Перенос времени выполняется через связь со студией.
Пока своих фотографий нет, раздел содержит явно подписанную иллюстрацию, а не портфолио.
